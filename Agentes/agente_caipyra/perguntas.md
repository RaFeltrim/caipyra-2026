# Roteiro de Perguntas - Agente Caipyra 2026

Estas são as perguntas estruturadas que você deve fazer ao chat do evento para se inteirar e complementar a documentação:

1. **Sobre as Palestras e Minicursos:**
   - "Quais foram todas as palestras e minicursos discutidos nesta conversa? Liste os títulos e palestrantes, se disponíveis."
   - "Quais foram os tópicos técnicos e práticos abordados no Mini Curso mencionado?"
   
2. **Sobre Códigos e Práticas:**
   - "Há algum trecho de código, exemplo prático ou repositório do GitHub que foi compartilhado neste chat sobre o evento?"
   - "Quais ferramentas, bibliotecas e pacotes Python foram recomendados para instalação e estudo?"

3. **Sobre Materiais de Apoio:**
   - "Foram compartilhados links para slides, PDFs ou artigos de referência sobre os temas do Caipyra 2026 neste chat?"
   - "Quais conceitos apresentados nas imagens ou discussões são mais críticos para detalharmos na apresentação de aprendizados?"

4. **Sobre o que ainda será visto:**
   - "Com base no histórico da conversa, há algum assunto ou palestra que foi mencionado como 'próximo passo' ou 'a ser visto' no evento?"
