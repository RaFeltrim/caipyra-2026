# Roteiro de Perguntas - Agente PDI e Roadmap

Estas são as perguntas estruturadas que você deve fazer ao chat do PDI/Roadmap para se inteirar e complementar a documentação:

1. **Sobre os Objetivos de Carreira:**
   - "Quais são as metas de carreira de curto, médio e longo prazo estabelecidas nesta conversa?"
   - "Qual é o cargo alvo e o nível de maturidade profissional que o usuário está buscando alcançar no momento?"

2. **Sobre as Competências do Roadmap:**
   - "Quais são as principais hard skills (tecnologias, frameworks, padrões de arquitetura) listadas no roadmap atual?"
   - "Existem soft skills recomendadas para desenvolvimento neste ciclo de PDI?"

3. **Sobre Planos de Ação e Prazos:**
   - "Quais ações práticas ou projetos foram sugeridos para o usuário realizar como parte do plano de ação?"
   - "Quais são os prazos ou marcos temporais definidos para a conclusão das metas de estudo?"

4. **Sobre Métricas de Evolução:**
   - "De que forma foi estruturado o acompanhamento de evolução do PDI (ex: checkpoints, revisões, feedback de lideranças)?"
