Trilhas Técnicas e Evidências

Orquestração Moderna (Airflow & Iceberg)

Como estruturar tabelas de alto desempenho em formato aberto analítico (Iceberg), com pipelines idempotentes no Airflow e rotinas automáticas de compactação de pequenos arquivos.

Processamento Distribuído (Dask)

Paralelização de tarefas e manipulação de conjuntos massivos de dados em Python que ultrapassam a memória RAM local, otimizando processamento com grafos acíclicos direcionados (DAGs).

Deep Learning e Python Fluente (PyTorch)

Construção de modelos com PyTorch aplicando boas práticas de clean code e orientação a objetos (usando ModulesDict e configs tipadas) ministrado pelos professores do ICMC-USP.

Resiliência em Automação (Playwright)

O uso de localizadores baseados em acessibilidade, tratamento nativo de abas e mocks de APIs de rede no Playwright para combater flaky tests em pipelines de testes funcionais.
