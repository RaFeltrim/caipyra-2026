1. VISÃO GERAL
Esta documentação reúne as informações e recursos compartilhados no tutorial prático sobre a utilização da API do Google Earth Engine (GEE) em conjunto com a linguagem Python para processamento distribuído de dados de sensoriamento remoto e inteligência geoespacial (Geospatial AI). O foco do tutorial foi demonstrar a transição entre o console Javascript clássico do GEE e fluxos de trabalho nativos e automatizados em Python.

2. CONCEITOS E FERRAMENTAS ABORDADAS
- Google Earth Engine (GEE):
  * Plataforma baseada em nuvem projetada para processamento de petabytes de dados de imagens de satélite e observações geoespaciais em escala global.
  * O processamento ocorre diretamente na infraestrutura do Google, permitindo que análises complexas rodem em segundos de forma paralela e otimizada.
- geemap:
  * Uma biblioteca em Python desenvolvida para visualização interativa e mapeamento de dados do Earth Engine.
  * Integra perfeitamente o GEE com Jupyter Notebooks, permitindo criar mapas interativos, plotar gráficos e realizar manipulações espaciais ricas de forma simplificada em Python.
- Integração e Automação:
  * Portabilidade de código Javascript do Code Editor do GEE para fluxos de scripts e notebooks Python funcionais.
  * Criação de dashboards geográficos interativos e pipelines automatizados de detecção de mudanças e análise de séries temporais de imagens.
