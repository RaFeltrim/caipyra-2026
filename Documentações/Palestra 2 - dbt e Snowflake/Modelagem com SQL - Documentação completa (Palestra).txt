1. VISÃO GERAL
Esta palestra aborda as melhores práticas de Engenharia de Dados com foco em modelagem e transformação direta no Snowflake AI Data Cloud utilizando a ferramenta dbt (data build tool). O objetivo é demonstrar como criar pipelines de dados eficientes, limpos e escaláveis usando apenas a linguagem SQL aliada a testes integrados.

2. CONCEITOS E ARQUITETURA ABORDADOS
- Paradigma ELT (Extract, Load, Transform): Em contraste com o tradicional ETL, os dados brutos são extraídos e carregados diretamente no Snowflake. O dbt então assume a etapa de transformação, executando consultas SQL otimizadas diretamente no poder de computação do Snowflake.
- dbt (data build tool): Ferramenta open-source que permite a engenheiros de dados modelar dados escrevendo instruções SQL SELECT básicas. Ela cuida de criar as tabelas e views correspondentes no banco de dados de maneira automatizada.
- Integração com Snowflake: Aproveita recursos essenciais do Snowflake, como:
  * Virtual Warehouses: Dimensionamento dinâmico e isolamento computacional para que consultas pesadas não impactem outras áreas do negócio.
  * Zero-Copy Clone: Clonagem instantânea de tabelas sem duplicação de dados, ideal para criar ambientes de homologação rápidos.
  * Suporte nativo a tipos complexos/semiestruturados (VARIANT) para processar payloads JSON nativos.

3. BOAS PRÁTICAS RECOMENDADAS
- Materializações Inteligentes: Uso de materialização do tipo view para dados que mudam rápido e tabelas (table) ou modelos incrementais (incremental) para tabelas muito grandes com o objetivo de economizar créditos computacionais.
- Testes de Qualidade de Dados: Escrita de testes YAML para validar regras de integridade diretamente no dbt (garantindo valores únicos, não nulos, integridade referencial, etc.).
- Linhagem de Dados Automatizada: Geração do grafo de linhagem de dados (lineage graph) para mapear e documentar o fluxo de dependências desde a origem até a entrega para os relatórios.
