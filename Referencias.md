## 🛠️ Ferramentas e Bibliotecas Recomendadas
- **Playwright (Python)**: [playwright.dev/python](https://playwright.dev/python/docs/intro) - Recomendado no PDI para migração de suíte de testes de UI robustos.
- **Ollama**: [ollama.com](https://ollama.com/) - Para rodar LLMs locais (Claude, Llama, Gemma, etc.) integrados em pipelines.
- **WeasyPrint**: [weasyprint.org](https://weasyprint.org/) - Biblioteca em Python utilizada para compilar o currículo em HTML/CSS para PDF de forma profissional.
- **urllib3**: [urllib3.readthedocs.io](https://urllib3.readthedocs.io/) - Biblioteca de resiliência e tratamento de retração exponencial (exponential backoff) para requisições HTTP em Python.
- **Microsoft Credentials Support**: [trainingsupport.microsoft.com](https://trainingsupport.microsoft.com/) - Fórum para abertura de chamado sobre o exame AB-620.
